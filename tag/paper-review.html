HintMR: Teaching Small Language Models to Reason Better via Stepwise Hint Guidance

HintMR introduces a two-SLM collaborative framework where a distilled hint-generating model provides step-by-step contextual hints to a reasoning SLM, boosting AIME-2024 accuracy from 20.69% to 68.97% while running entirely inference-time without any LLM dependency.

Learning to Seek Help: How SLMs Dynamically Collaborate with LLMs for Better Reasoning

A dynamic collaboration framework where a small language model learns via reinforcement learning to proactively decide when and how to request help from a large language model during multi-step reasoning, significantly outperforming static pipelines while respecting efficiency and privacy constraints.
